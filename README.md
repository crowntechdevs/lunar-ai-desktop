🌙 LUNAR™ — Open-Source 3D Desktop Companion & System AI Agent
Powered by CrownAI™ | Designed under Crown Tech™ Architectural & Warm Titanium Standards
LUNAR™ is an interactive, lightweight 3D AI companion and system engine designed to live natively on your desktop. Inspired by Zaha Hadid’s fluid biomorphic architecture and modern tactile luxury, it replaces rigid desktop environments with warm titanium surfaces, satin bronze highlights, and frosted glass dynamic UI.
🎨 Visual Identity & Features
3D Animated Companion: Expressive designer-toy avatar seated in a matte curved pod with dynamic real-time states (Idle, Greeting, Thinking, Coffee Break).
Tactile Warm Titanium UI: Deep dark mocha-obsidian base (#141110) with satin copper/bronze details (#C88A58) and frosted glass surfaces.
Privacy-First Core: Powered by open-source LLMs (Llama 3 / DeepSeek) using low-latency local or private endpoint calls via CrownAI™ Orchestrator.
System Automation Agent: Capability to execute system tasks, file searches, and application launches via natural voice or text commands.
Biomorphic Layout: Soft organic curves, rounded window frames, minimal search pill, and fluid dock widgets.
🏗️ Architecture Stack
3D Rendering: Three.js / WebGL / Spline Engine
AI Logic Core: System-prompt injected Open-Source Models via CrownAI™ Orchestrator
Interface: Warm Titanium & Frosted Glassmorphism CSS / Minimalist Widgets
