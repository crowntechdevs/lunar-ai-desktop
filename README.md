# 🌙 LUNAR™ — Open-Source 3D Desktop Companion & System AI Agent

> **Powered by CrownAI™ | Architectural Warm Titanium & Satin Bronze Design System**

LUNAR™ is an interactive, lightweight 3D AI companion and system engine designed natively for **CrownOS™**. Grounded in fluid biomorphic architecture, soft organic contours, and a warm titanium-mocha color identity, it completely reimagines the traditional desktop experience.

---

## 🎨 Visual Identity & Architectural Aesthetics

* **Base Palette:** Rich Warm Titanium & Dark Mocha-Obsidian (`#141110`)
* **Accents & Trim:** Satin Bronze & Copper Highlights (`#C88A58`) with Clean Warm-White Indicators
* **Interface Geometry:** Soft organic fluid curves, frosted glassmorphism (`backdrop-filter: blur`), and zero harsh rectangular angles
* **3D Avatar Engine:** Living designer-toy companion (LUNAR™) housed inside a curved matte-finish pod with real-time micro-states (`Idle`, `Greeting`, `Thinking`, `Coffee Break`)

## 🏗️ Technical Architecture Stack

* **3D Rendering & Avatar Engine:** Three.js / WebGL / Spline Runtime (`@splinetool/runtime`)
* **AI Logic Core:** CrownAI™ Orchestrator powered by local / private open-source LLMs (Llama 3 / DeepSeek)
* **UI & Styling:** Biomorphic Glassmorphism CSS, Dynamic Canvas Overlays, and Custom SVG Iconography
* **System Automation:** Native system control hooks, file indexers, and voice/text prompt pipelines
